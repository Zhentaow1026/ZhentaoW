## Part 1 — FASTQ to multi-population sync

### 1. Configure paths

Edit `config/paths.sh`:

Main variables:
- `FASTQDIR`: directory containing the raw fastq files named like `4675551.FASTQ.gz`
- `REF`: reference genome fasta (`ref/Amel_HAv3.1.fna`)
- `SCR`: directory
- `CONDA_ENV`: conda env name (`popoolation2`)
- `P2JAR`: path to `mpileup2sync.jar` (optional; if empty, scripts may infer from `$CONDA_PREFIX`)

### 2. Merge FASTQs by genotype

Run:
```bash
bash scripts/01A_make_young_feral_fastq.sh
bash scripts/01B_make_young_managed_fastq.sh
bash scripts/01C_make_batlow_feral_fastq.sh
bash scripts/01D_make_batlow_managed_fastq.sh
```

### 3. Mapping with BWA and samtools using SLURM arrays
Each array task maps one genotype FASTQ:
- `bwa aln` → `.sai`
- `bwa samse` → `.sam`
- `samtools view -q 20` filter
- `samtools sort` → `.bam`
- `samtools index` → `.bam.bai`
- copy `BAM/BAI` back to `$BASE/map/<group>/`


Submit mapping jobs:
```
sbatch scripts/02A_map_young_feral_array.sbatch
sbatch scripts/02B_map_young_managed_array.sbatch
sbatch scripts/02C_map_batlow_feral_array.sbatch
sbatch scripts/02D_map_batlow_managed_array.sbatch
```

```

Output: 
```

```

### 04C PERMANOVA (adonis2 analysis)
This repository contains an R workflow to test the effects of **region** and **management status (feral vs managed)** on genetic distance using **PERMANOVA** (`adonis2` in the `vegan` package).

Input:
- `results/distance_matrix_cailliez.csv`  
  - Rows and columns are sample IDs: `P1` to `P46`
  - Distances were corrected using the **Cailliez** method
- `results/pool_metadata_all_regions1.csv`

Sample group definition:
- Young (feral): P1–P10  
- Young (managed): P11–P20  
- Batlow (feral): P21–P32  
- Batlow (managed): P33–P46

Models:
- Interaction model:
  ```r
  adonis2(dist ~ region * feral, by = "margin")
- Additive model (used when interaction is not significant):
  ```r
  adonis2(dist ~ region + feral, by = "margin")

Handling of negative distances:
Although Cailliez correction should produce non-negative distances, small or moderate negative values were still present in the matrix.
To satisfy adonis2 requirements, all negative values were truncated to zero before analysis.

Run (Windows PowerShell):
```
cd scripts\R
Rscript .\adonis_workflow.R "..\..\results\distance_matrix_cailliez.csv"
```

## Part 3— Two-population PoPoolation2 analysis

### Batlow region analysis
This section performs PoPoolation2 analysis comparing Batlow feral and Batlow managed populations using a two-population .sync file generated from merged BAM files.

Workflow:
- Merge BAM files within each group (feral and managed)
- Generate mpileup and convert to 2-population .sync
- Calculate allele frequency differences
- Calculate Fst for every SNP
- Calculate Fst values using a sliding window approach (500 bp)
- Fisher’s exact test

Input:
- 2-population sync file:
  - `sync/batlow_F_vs_M_2pop1.sync`
  - Population order in the .sync file:
    - Batlow feral
    - Batlow managed

Sync generation (merged BAM → mpileup → sync):
- The .sync file is generated by merging BAMs within each group and running mpileup
- Run:
```bash
sbatch scripts/batlow/05A_slurm_batlow_make_sync_2pop1.sbatch
```

#### 1–4. Allele frequency difference, FST per SNP, windowed FST, and Fisher’s exact test
- This combined pipeline performs:
  - Allele frequency differences
  - FST per SNP
  - FST in sliding windows (500 bp)
  - Fisher’s exact test
- Run:
```bash
sbatch scripts/07A_Batlow_allelefrequency_diff+FST_per_SNP+FST_window+Fisher_exact_test.sbatch
```
- Output (in `pop2_batlow_2pop1/`):
  - `batlow_F_vs_M_2pop1_pwc`
  - `batlow_F_vs_M_2pop1_rc`
  - `batlow_F_vs_M_2pop1.SNP.fst`
  - `batlow_F_vs_M_2pop1.W500.fst`
  - `batlow_F_vs_M_2pop1.W500.fst`
  - `batlow_F_vs_M_2pop1.fet`

#### 5. Coverage inspection (Batlow 2-population sync)
Coverage was extracted from the two-population sync file to determine appropriate coverage thresholds and to visualise depth distributions.

Input:
- `sync/batlow_F_vs_M_2pop1.sync`

Step 1: Extract coverage and summary statistics
- Extracts per-site coverage values from the .sync file
- Computes summary statistics to guide filtering thresholds
- Run:
```bash
bash scripts/06A_cov_from_sync_batlow.sh
```
- Output:
  - `results/coverage/batlow_F_vs_M_2pop1.coverage.tsv`
- The script reports:
  - Minimum, mean, and maximum coverage
  - Coverage percentiles
  - Suggested `max_coverage` threshold

Step 2: Plot coverage histograms
- Generates coverage distribution plots for each population
- Run:
```bash
python scripts/06A_batlow_plot_coverage.py
```
- Output:
  - `results/coverage/batlow_F_vs_M_2pop1.pop1.coverage.hist.png`
  - `results/coverage/batlow_F_vs_M_2pop1.pop2.coverage.hist.png`
